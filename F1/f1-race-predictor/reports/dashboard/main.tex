\section{Overview}

The F1 Race Predictor is a machine learning system that predicts Formula 1 race
finishing positions for all 20 drivers using historical telemetry, driver
performance, team statistics, and weather data. The system achieves
\textbf{92\% top-3 accuracy} on the 2025 season.

\section{System Components}

\begin{itemize}
    \item \textbf{Data Pipeline}: Automated extraction from FastF1 API
          (2020--2025, ~120 race weekends)
    \item \textbf{Feature Engineering}: 50+ features across lap, driver,
          constructor, and weather categories
    \item \textbf{Models}: XGBoost (primary), PyTorch neural network, grid baseline
    \item \textbf{API}: FastAPI REST service for real-time predictions
    \item \textbf{Testing}: 80\%+ unit test coverage with temporal validation
\end{itemize}

\section{Top Features by Importance}

\begin{enumerate}
    \item Average lap time (last 5 laps)
    \item Grid / qualifying position
    \item Constructor season average points
    \item Weather aggressiveness score
    \item Driver rolling 5-race average finishing position
\end{enumerate}
