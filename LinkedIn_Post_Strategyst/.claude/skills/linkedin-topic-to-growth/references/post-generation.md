# Post Generation Rules

Expand each chronogram row into a publish-ready LinkedIn post. **Write all post copy in
Spanish** (hook, body, insight, takeaway, CTA, hashtags, engagement question), unless the
user explicitly requests another language.

## Post Anatomy (every post)

Produce these parts, in order, inside one ready-to-copy block:

1. **Hook** — first 1–2 lines. Must stop the scroll. Specific, not clickbait. Avoid
   "¿Sabías que…?" filler.
2. **Body** — short paragraphs / line breaks for mobile readability. One idea developed.
3. **Insight** — the non-obvious point: the "so what" the reader couldn't get elsewhere.
4. **Practical takeaway** — something the reader can apply today (a step, a check, a rule).
5. **CTA** — one clear action aligned to the post's goal (comment, save, follow, DM, click).
6. **Engagement question** — one genuine question that invites replies.
7. **Hashtags** — 3–5 relevant, specific hashtags (mix of broad + niche). No hashtag spam.

## Formatting Rules

- Short lines and white space; LinkedIn truncates after ~3 lines, so the hook must earn the
  "…ver más" click.
- One idea per post. If two ideas appear, split into two posts.
- Use concrete examples, numbers the user actually has, and plain language.
- Emojis: sparingly and purposefully (0–3), only if it fits the chosen tone.
- No walls of text; no more than ~1,300–1,800 characters for standard posts.

## Tone Mapping

Adapt voice to the `tone` input:

| Tone | Voice cues |
|------|-----------|
| professional | precise, calm, credible |
| bold | strong claims, short punchy lines, takes a stance |
| educational | structured, defines terms, step-by-step |
| inspirational | story-led, forward-looking (avoid empty motivation) |
| technical | exact terminology, depth, defensible detail |
| simple | plain words, one concept, accessible |
| storytelling | scene → tension → resolution → lesson |

## Depth Mapping

- `beginner_friendly` → define jargon, start from fundamentals.
- `expert` → assume domain fluency, go deep, skip basics.
- `mixed` → lead accessible, end with a deeper layer for experts.

## Carousel Posts

For carousel format, instead of one body, produce a **slide-by-slide outline** (Slide 1
hook → slides 2–N one idea each → final slide CTA), plus the LinkedIn caption in Spanish.

## Hard Rules

- **No invented facts, stats, studies, or quotes.** If unsourced, reframe as the author's
  reasoning/experience and label it.
- **No generic motivational posts** unless the user requested them.
- **Respect `avoid`** at all times.
- Every post must pass `quality-checklist.md` before it is presented.
- Make every post unmistakably specific to the user's topic and audience.
