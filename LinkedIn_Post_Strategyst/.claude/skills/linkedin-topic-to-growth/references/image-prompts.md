# Image / Carousel Prompt Rules

For every post, produce one prompt suitable for an AI image generator (or a designer
brief). The prompt describes the visual — it is not the post copy. Prompts may be written
in English (image models perform well in English); any **text overlay shown in the image
must be in Spanish** to match the post.

## Required Fields per Prompt

| Field | Description |
|-------|-------------|
| **Visual concept** | The core idea/metaphor of the image in one sentence. |
| **Style** | e.g., clean flat illustration, editorial photo, minimal data-viz, 3D render. |
| **Layout** | Composition: focal point, grid, single subject, diagram, slide template. |
| **Text overlay suggestion** | Short Spanish headline/label to place on the image (or "none"). |
| **Color palette** | 2–4 colors, ideally aligned to a consistent brand look across posts. |
| **Audience mood** | The feeling it should evoke (trustworthy, energetic, analytical…). |
| **Avoided elements** | What to exclude (clichés, stock-photo handshakes, clutter, fake charts). |

## Format-Specific Guidance

- **Single image post:** one strong focal visual + minimal Spanish overlay.
- **Carousel:** provide a cover-slide prompt plus a repeatable template description for
  inner slides (consistent palette, type, and layout across slides).
- **Poll / text post:** image optional; if used, keep it simple and supportive.

## Rules

- Keep a **consistent visual identity** across the calendar (same palette/style family) so
  the feed looks coherent and recognizable.
- Overlay text must be **short** and legible on mobile (a few words).
- **Never fabricate data visuals** that imply real statistics the user doesn't have; use
  clearly illustrative/abstract charts or label them as illustrative.
- Respect `avoid` (styles or formats the user excluded).
- Prefer accessible contrast and uncluttered composition.

## Example Prompt

> **Visual concept:** A single funnel where most of the flow leaks out the sides, only a
> thin stream reaching the bottom — the gap between vanity reach and real retention.
> **Style:** clean minimal flat illustration, editorial.
> **Layout:** centered funnel, generous negative space, focal point upper-center.
> **Text overlay (ES):** "Alcance ≠ Retención".
> **Color palette:** deep navy, white, one accent amber.
> **Audience mood:** analytical, credible.
> **Avoided elements:** stock photos, handshakes, fake precise numbers, clutter.
